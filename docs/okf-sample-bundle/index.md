# OKF sample bundle

A small, living OKF v0.1 bundle exported from a Tessera vault. It is a
conformant reference example: every concept carries parseable frontmatter
with a non-empty `type` and a `tessera_external_id`, and the compiled
notebook's citations resolve to other concepts in the bundle.

# Concepts

* [preference](preference/) - personal preferences
* [workflow](workflow/) - working agreements
* [compiled_notebook](compiled_notebook/) - compiled task briefs
